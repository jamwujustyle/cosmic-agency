## Запуск через Docker (Рекомендуется)

Проект полностью докеризован. Для запуска используется `docker-compose.yml`, который включает три сервиса:

- `db` — официальный образ MySQL.
- `migrator` — "умный" сервис-мигратор, который дожидается поднятия базы, создает её (если нет), динамически проверяет и выполняет все миграции, а также гарантирует создание суперпользователя (`admin` / `admin`).
- `web` — само приложение Django, стартует только после успешной работы мигратора.

Для запуска выполните:

```bash
docker compose up -d --build
```

После старта контейнеров приложение будет доступно по адресу `http://127.0.0.1:8000/`.

> **💡 Просмотр на мобильном устройстве:** Чтобы проверить адаптивную вёрстку на реальном телефоне, можно создать временный публичный туннель:
>
> ```bash
> npx cloudflared tunnel --url http://localhost:8000
> ```
>
> Команда выдаст публичный URL вида `*.trycloudflare.com`, который можно открыть на телефоне.

## Локальный запуск (Без Docker)

1. Установите зависимости из файла `req.pip`:
   ```bash
   pip install -r req.pip
   ```
2. Убедитесь, что у вас запущен локальный сервер MySQL и создана база данных `slider_db` (пользователь `root`, без пароля, порт `3306`). При необходимости параметры можно изменить в `config/settings.py`.
3. Примените миграции:
   ```bash
   python manage.py migrate
   ```
4. Создайте суперпользователя для входа в админку:
   ```bash
   python manage.py createsuperuser
   ```
5. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
6. Админка доступна по адресу `http://127.0.0.1:8000/admin/`, а сам лендинг — `http://127.0.0.1:8000/`.
